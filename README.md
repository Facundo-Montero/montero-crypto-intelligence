# MONTERO CRYPTO INTELLIGENCE (MCI)

Plataforma de investigación de criptoactivos enfocada en evidencia, fundamentos, riesgos y contexto de mercado. MCI no emite señales automáticas de compra ni garantiza rendimientos.

## Estado

Proyecto en construcción. La primera versión prioriza transparencia metodológica: separar datos observables, estimaciones e hipótesis; mostrar fuentes y fechas; y declarar evidencia insuficiente cuando falten datos relevantes.

## Despliegue gratuito

La aplicación está pensada para ejecutarse en Streamlit Community Cloud usando este repositorio. No requiere VPS ni cambios en el plan de Hostinger.

## Principios

- El score, si se utiliza, es un índice de investigación y no una probabilidad de suba.
- Stablecoins, wrapped assets y activos sintéticos se clasifican aparte del radar de crecimiento.
- Liquidez, volumen y momentum no se presentan como fundamentos.
- Los datos faltantes no se inventan ni se reemplazan por proxies engañosos.
- La plataforma es informativa; cualquier decisión de inversión requiere investigación independiente.
